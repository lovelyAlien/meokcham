## 1. 확정한 결정

| # | 질문 | 결정 | 근거 |
| --- | --- | --- | --- |
| U1 | 홈 잔디 기본 범위 | **최근 6개월**을 크게 보여주고, **"전체 보기"**에서 1년을 본다 | 폭 375pt에서 1년(53열)은 칸이 약 5pt라 탭하기 어렵다. 6개월(26열)은 칸 11pt 안팎이다. [PRD 5.2](PRD.md)의 "최근 N개월로 접기"와 같은 방향이다 |

## 2. 화면 목록과 경로

앱 현재 라우트(`app/src/app`)에 **새로 필요한 화면은 온보딩 2개와 잔디 전체 보기**다.

| 화면 | 경로 | 상태 | 기능 |
| --- | --- | --- | --- |
| 로그인 | `(auth)/login` | 기존 | Apple/Google 로그인 |
| 온보딩 1: 금지 음식 | `onboarding/foods` | **신규** | F1 |
| 온보딩 2: 알림 | `onboarding/notification` | **신규** | F4 |
| 홈 | `(tabs)/index` | 기존 | F2, F3 |
| 통계 | `(tabs)/stats` | 기존 | F5 |
| 설정 | `(tabs)/settings` | 기존 | 알림, 타임존, 계정 |
| 금지 음식 관리 | `foods/index` | 기존 | F1 |
| 하루 기록·정정 | `record/[date]` | 기존, 모달 | F2, F6 |
| 잔디 전체 보기 | `grass` | **신규** | F3 |

- 로그인 직후 `isNewUser`가 `true`이거나 활성 금지 음식이 0개이면 온보딩으로, 아니면 홈으로 보낸다.
- 바텀시트(먹은 음식 선택)는 별도 경로가 아니라 홈과 `record/[date]`가 함께 쓰는 컴포넌트다.

## 3. 온보딩

```
로그인 → [1] 금지 음식 고르기 → [2] 알림 시각 → (권한창) → 홈
```

### 3.1 금지 음식 고르기 (`onboarding/foods`)

- 제목: "끊고 싶은 음식을 골라 보세요"
- 예시 칩을 여러 개 고를 수 있다: 라면, 과자, 탄산음료, 야식, 커피, 술, 밀가루, 설탕 음료 *(예시 목록 내용은 [미결 사항](#12-미결-사항) 1번)*
- 아래에 "직접 추가" 입력창이 있다. 이름은 1~50자.
- **최소 1개, 최대 10개**([API 명세 D1](API_SPEC.md)). 10개가 되면 나머지 칩은 비활성으로 바뀌고 "최대 10개까지 고를 수 있어요"를 보여준다.
- 보조 문구: "서비스가 정해주는 목록이 아니에요. 내가 정한 규칙이에요." ([신념 5](PRD.md))
- "다음" 버튼은 1개 이상 고르면 활성화된다. 누르면 선택한 음식마다 `POST /foods`를 호출한다.

### 3.2 알림 시각 (`onboarding/notification`)

- 제목: "매일 한 번, 알려드릴게요"
- 시각 선택(기본 21:00)과 "알림 받기" 토글(기본 켬).
- 보조 문구: "오늘 이미 기록했다면 알림은 오지 않아요."
- "시작하기"를 누르면 `PUT /notification-settings`로 저장하고, 알림 토글이 켜져 있으면 **그때 iOS 알림 권한창을 띄운다**(U3). 허용되면 푸시 토큰을 `POST /push-tokens`로 등록한다.
- 권한을 거절하거나 토글을 끈 채 시작해도 홈으로 진입할 수 있다. 거절한 경우 설정 탭에 안내가 남는다([7.2](#72-알림-항목)).
- "나중에 할게요" 링크: 알림 설정과 권한 요청 없이 홈으로 간다(알림 기본값 행은 가입 시 이미 만들어져 있다).

## 4. 홈

첫 화면에서 **오늘 상태와 잔디가 바로 보인다**([한눈에 원칙](PRD.md)). 위에서 아래로:

```
┌──────────────────────────┐
│ 10월 22일 (수)            │  ← 서버가 준 today
│ ┌──────────────────────┐ │
│ │  오늘 지켰나요?        │ │  ← 오늘 기록 카드
│ │ [ 안 먹었다 ] [ 먹었다 ]│ │
│ └──────────────────────┘ │
│  🔥 4일 연속               │  ← 현재 스트릭 (0이어도 표시)
│ ┌──────────────────────┐ │
│ │ 잔디 (최근 6개월)      │ │
│ │ ░░▓▓░▓▓▓░ ...         │ │
│ │          전체 보기 ›   │ │
│ └──────────────────────┘ │
└──────────────────────────┘
        홈 | 통계 | 설정
```

### 4.1 오늘 기록 카드

| 상태 | 표시 | 동작 |
| --- | --- | --- |
| 미기록 | "오늘 지켰나요?" + **[안 먹었다]** **[먹었다]** | 안 먹었다 → `PUT /records/today` `{eatenFoodIds: []}` 즉시 저장. 먹었다 → 바텀시트 |
| 지킴 | "오늘도 지켰어요" + 작은 "수정" | 수정 → 바텀시트(선택 없음 상태) |
| 어김 | "오늘은 {음식}을 먹었어요. 내일 다시 해봐요" + "수정" | 수정 → 바텀시트(기존 선택 유지) |

- "안 먹었다"는 **낙관적 업데이트**로 탭 즉시 카드가 "지킴"으로 바뀌고, 실패하면 되돌린 뒤 토스트로 알린다(TanStack Query).
- 같은 날 수정은 같은 `PUT`을 다시 보낸다(덮어쓰기).
- 날짜는 서버가 준 `today`를 쓴다. 04:00 이전에 열면 전날 날짜가 표시된다는 점을 사용자가 이해하도록, 04:00 이전에는 카드 아래에 작은 안내를 둔다: "새벽 4시까지는 어제 기록이에요."
- 금지 음식이 0개면 카드를 숨기고 [빈 상태](#8-빈-상태와-에러)를 보여준다(`NO_FORBIDDEN_FOODS`).

### 4.2 먹은 음식 바텀시트 (U2)

```
┌──────────────────────────┐
│ 어떤 음식을 먹었나요?      │
│ [라면✓] [과자] [탄산✓]     │  ← 칩, 다중 선택
│ [ 완료 ]                  │  ← 1개 이상 선택해야 활성
└──────────────────────────┘
```

- 칩은 현재 활성 금지 음식 전체다. 최소 1개를 골라야 "완료"가 활성화된다("먹었다"인데 아무것도 안 고르는 상태를 막는다).
- 완료 → `PUT /records/today` `{eatenFoodIds: [...]}`. 시트가 닫히고 카드가 "어김"으로 바뀐다.
- 격려 톤: 완료 후 토스트는 "기록했어요. 솔직하게 남긴 것만으로 충분해요."

### 4.3 잔디 (최근 6개월)

- 7행(월~일 또는 일~토, [미결 사항](#12-미결-사항) 2번) × 26열. 칸 11pt + 간격 2pt.
- 세 상태: 지킴(초록), 어김(빨강), 미기록(회색). 미래 날짜 칸은 그리지 않는다.
- **오늘 칸은 테두리로 강조**한다.
- 데이터는 `GET /grass`(기본 366일)를 받아 앱에서 최근 6개월만 그린다. 홈과 전체 보기가 같은 캐시를 쓴다.
- 칸을 탭하면 [잔디 상세](#5-잔디-상세와-소급-기록)를 연다.

## 5. 잔디 상세와 소급 기록

### 5.1 칸 탭 시: 텍스트 상세 (접근성 요건)

색만으로 의미를 전달하지 않기 위해([PRD 5.2](PRD.md)) 칸을 탭하면 하단 시트에 텍스트로 보여준다.

| 상태 | 표시 |
| --- | --- |
| 지킴 | "10월 20일 (월) · 지킴" |
| 어김 | "10월 21일 (화) · 어김 · 라면, 탄산" |
| 미기록 | "10월 19일 (일) · 기록 없음" |

- 시트에 **[기록하기] / [수정하기]** 버튼이 있다. 누르면 `record/[date]` 모달로 이동한다.
- 과거 날짜는 제한 없이 소급·정정할 수 있다([API 명세 D3](API_SPEC.md)). 미래 칸은 그려지지 않으므로 누를 수 없다.

### 5.2 하루 기록·정정 (`record/[date]`, 모달)

- 홈의 오늘 기록과 같은 구성이다. 상단에 날짜, "안 먹었다 / 먹었다" 선택, 먹었다면 칩 선택, "저장".
- 이미 기록이 있으면 `GET /records/{date}`로 불러와 현재 값을 채운다. 없으면 `404 RECORD_NOT_FOUND`이므로 빈 상태로 시작한다.
- 소급 기록에서는 안내 문구를 둔다: "지금의 금지 음식 목록을 기준으로 저장돼요." ([API 명세 D3](API_SPEC.md)의 영향)

### 5.3 잔디 전체 보기 (`grass`)

- 최근 1년(53열)을 한 화면에 보여준다. 칸이 작으므로 **정확한 선택보다 흐름 파악용**이다.
- 칸을 탭하면 같은 텍스트 상세 시트가 열린다. 작은 칸 때문에 오탭이 나기 쉬워, 탭한 칸과 주변 칸을 확대해서 보여주는 방식은 [미결 사항](#12-미결-사항) 3번이다.
- 상단에 범례(지킴 / 어김 / 기록 없음)를 색과 **텍스트로** 함께 보여준다.

## 6. 통계

`GET /stats`의 값을 그대로 보여준다.

| 항목 | 표시 |
| --- | --- |
| 현재 연속 | "4일 연속" |
| 최장 연속 | "최장 12일" |
| 누적 지킨 날 | "지금까지 37일 지켰어요" (스트릭이 끊겨도 줄지 않는 지표, [신념 4](PRD.md)) |
| 이번 달 | "이번 달 15/20일 · 75%" — 분모는 기록한 날([API 명세 D2](API_SPEC.md)) |

- 스트릭이 0이어도 부정적으로 표현하지 않는다. "오늘부터 다시 시작해요"처럼 중립·격려 문구를 쓴다.
- 기록이 하나도 없으면 [빈 상태](#8-빈-상태와-에러)를 보여준다. 이번 달 기록이 없으면 비율은 `—`로 표시한다(`keptRate`가 `null`).

## 7. 설정과 금지 음식 관리

### 7.1 설정 탭 구성

| 항목 | 내용 |
| --- | --- |
| 금지 음식 | `foods/index`로 이동 (개수 "3/10" 표시) |
| 알림 | [7.2](#72-알림-항목) |
| 타임존 | 현재 타임존 표시와 변경 (`PATCH /users/me`). 기기 타임존이 달라졌으면 변경할지 묻는다 |
| 로그아웃 | `POST /auth/logout`, 푸시 토큰 해제 |
| 계정 삭제 | 확인 모달 후 `DELETE /users/me`. 문구: "모든 기록이 삭제되고 되돌릴 수 없어요" |
| 안내 | 앱 버전, "먹참은 건강 조언이나 의료적 판단을 하지 않아요" ([PRD 5.4](PRD.md)) |

### 7.2 알림 항목

- 토글과 시각 선택 (`PUT /notification-settings`).
- OS 권한이 거절된 상태이면 토글 아래에 안내와 버튼을 보여준다: "알림이 꺼져 있어요. 시스템 설정에서 켤 수 있어요." → **[설정 열기]**.
- 권한이 허용되어 있는데 서버 설정만 꺼져 있다면, 일반 토글 상태로 보여준다.

### 7.3 금지 음식 관리 (`foods/index`)

- 목록: 이름 + 삭제. 이름을 탭하면 이름 변경. 아래에 "추가" 입력창. 10개가 되면 추가가 비활성이다.
- 삭제 확인 문구: "삭제해도 지난 기록은 그대로 남아요." (스냅샷이 보존됨, [PRD 5.3](PRD.md))
- 이름 변경도 과거 기록에는 영향이 없다고 안내한다.
- 에러: 중복 이름(`FOOD_NAME_DUPLICATED`)은 입력창 아래에 "이미 있는 음식이에요", 한도 초과(`FOOD_LIMIT_EXCEEDED`)는 "최대 10개까지 등록할 수 있어요".

## 8. 빈 상태와 에러

| 상황 | 표시 |
| --- | --- |
| 금지 음식 0개 (홈) | 카드 대신 "먼저 끊고 싶은 음식을 정해 볼까요?" + [음식 정하기] |
| 첫 사용, 기록 0건 (홈 잔디) | 전부 회색. 카드 아래에 "오늘이 첫 칸이에요" |
| 통계, 기록 0건 | "기록을 시작하면 여기에 쌓여요" |
| 네트워크 오류 | 토스트 "연결이 불안정해요. 잠시 후 다시 시도해 주세요" + 재시도. 마지막으로 불러온 잔디는 캐시로 계속 보여준다 |
| 로그인 만료 | `INVALID_REFRESH_TOKEN`이면 로그인 화면으로. 기록 화면에서 작성 중인 선택은 잃지 않도록 먼저 저장 시도를 안내한다 |

- 서버 에러 `detail` 문자열은 사용자에게 그대로 보여주지 않는다. 앱이 `code`별 문구를 정한다([API 명세 1.2](API_SPEC.md)).

| `broken` | `#CF222E` | `#F85149` | 어김 |
| `empty` | `#EBEDF0` | `#2D333B` | 미기록 |
| `text` / `textSecondary` | `#1F2328` / `#60646C` | `#F0F6FC` / `#B0B4BA` | 본문 / 보조 |
| `background` / `backgroundElement` | `#FFFFFF` / `#F0F0F3` | `#0D1117` / `#212225` | 바탕 / 카드 |

- 간격은 `Spacing`(4pt 기반)을 쓴다. 잔디 칸은 11pt, 간격 2pt.
- 세 상태는 라이트·다크 모두에서 서로 구분되어야 한다([PRD 5.2](PRD.md)). 구현 시 실제 대비를 확인한다.
- 초록/빨강만으로는 색각 이상 사용자가 구분하기 어렵다. 칸 탭 시 텍스트 상세와 범례 텍스트로 보완하고, 어김 칸에 보조 표식(예: 안쪽 작은 점)을 넣을지는 [미결 사항](#12-미결-사항) 4번이다.

## 10. 문구 원칙과 알림 문구

[비난하지 않는 톤 원칙](PRD.md)에 따라 어긴 날에도 중립이거나 격려하는 문구를 쓴다. 경고음, 진동, 실패 강조 연출은 쓰지 않는다.

| 상황 | 문구 |
| --- | --- |
| 미기록 카드 | "오늘 지켰나요?" |
| 지킨 날 | "오늘도 지켰어요" |
| 어긴 날 | "오늘은 {음식}을 먹었어요. 내일 다시 해봐요" |
| 어김 기록 완료 토스트 | "기록했어요. 솔직하게 남긴 것만으로 충분해요" |
| 스트릭 끊김 | "누적 37일 지켰어요. 오늘부터 다시 쌓아요" |

**푸시 알림** ([API 명세 8.5](API_SPEC.md))

- 제목: "오늘 지켰나요?" / 본문: "먹고 싶었지만 참았나요?"
- 액션 버튼: **[안 먹었다]**, **[먹었다]**. 두 버튼 모두 앱을 열고([API 명세 D4](API_SPEC.md)), "안 먹었다"는 열리자마자 오늘 칸에 자동 기록한 뒤 완료 화면(지킴 카드)을 보여준다. "먹었다"는 먹은 음식 바텀시트가 열린 홈으로 간다.

## 11. 접근성

- **색만으로 전달하지 않는다.** 칸 탭 텍스트 상세, 범례 텍스트, 카드 문구가 상태를 글로 알려준다.
- 잔디 칸 하나하나에 `accessibilityLabel`("10월 21일, 어김, 라면 탄산")을 붙인다. 스크린 리더 사용자가 182칸(6개월)을 모두 순회하지 않도록 잔디 전체를 하나의 요약 요소("최근 6개월 중 지킨 날 88일, 어긴 날 12일")로 묶고, 상세는 목록 보기로 제공하는 방식을 구현 시 검토한다.
- 버튼과 칩의 터치 영역은 최소 44pt다. 잔디 칸(11pt)은 이보다 작으므로, 칸 탭 시 상세를 여는 동작에 의존하지 않고 같은 정보를 접근 가능한 목록으로도 제공한다([미결 사항](#12-미결-사항) 3번).
- 다크 모드에서도 세 상태를 구분한다.
- 시스템 글자 크기 설정을 따른다(고정 높이 대신 `minHeight` 사용).
